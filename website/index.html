Versão 0.1.27 — Multiplataforma (Linux & Windows)

Sincronização bidirecional nativa, simples e segura para Linux e Windows

Mantenha pastas locais em sincronia contínua com o Google Drive para trabalho offline. Com operação em segundo plano, salvaguardas contra exclusões acidentais, integração ao cofre do sistema e soberania absoluta dos seus arquivos.

Recursos e Arquitetura

Desenvolvido para confiabilidade e respeito à sua privacidade

Tudo o que você precisa para manter arquivos sincronizados com segurança sem abrir mão do controle da sua máquina.

Sincronização Bidirecional Confiável

Baseada no motor rclone bisync integrado, com conferência rigorosa de integridade por hash SHA-256, horário de modificação e tamanho de arquivo.

Proteção Contra Exclusão em Massa

Salvaguardas automáticas que abortam o ciclo se mais de 50% ou 25 arquivos forem apagados localmente, evitando que exclusões acidentais se propaguem para a nuvem.

Operação em Segundo Plano e Bandeja

Fechar a janela apenas oculta a interface gráfica. O serviço de usuário gerencia as sincronizações periódicas de 5 em 5 minutos e integra-se à bandeja do desktop.

Cofre do Sistema e Memória Segura

Tokens de acesso armazenados de forma criptografada no GNOME Keyring ou KWallet. As configurações do motor rodam em /dev/shm efêmero e são destruídas pós-uso.

Temas Claro e Escuro (WCAG AAA)

Aparência adaptativa acompanhando o sistema operacional ou selecionável manualmente, com seletores vetoriais nítidos e contraste independente para a bandeja.

Zero Telemetria e Soberania Total

Sem anúncios, sem analytics e sem servidores intermediários. Toda a comunicação ocorre exclusivamente entre seu computador e as APIs oficiais da Google via HTTPS.

Distribuição e Pacotes

Instalação simples no Arch Linux, Manjaro e BigLinux

O pacote oficial .pkg.tar.zst inclui o binário integrado do motor e registra todos os arquivos de sistema.

Downloads Oficiais do BrisaSync v0.1.27: Escolha o formato ideal para o seu sistema:

Arch / Manjaro (.pkg.tar.zst) Debian / Ubuntu (.deb) Universal Linux (.AppImage) Windows x64 (.exe) Todas as Releases no GitHub →
Terminal — Instalação e Execução 
# Arch Linux / Manjaro / BigLinux
sudo pacman -U brisasync-0.1.27-1-x86_64.pkg.tar.zst

# Debian / Ubuntu / Linux Mint
sudo apt-get install ./brisasync_0.1.27-1_amd64.deb

# AppImage Universal
chmod +x BrisaSync-0.1.27-x86_64.AppImage && ./BrisaSync-0.1.27-x86_64.AppImage

# Gerenciar serviço de sincronização do usuário (Linux)
systemctl --user start brisasync.service
systemctl --user status brisasync.service
