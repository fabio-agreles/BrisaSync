Como criar seu próprio projeto OAuth no Google Cloud

O BrisaSync já vem com um projeto OAuth próprio, mas você pode criar o seu gratuitamente no Google Cloud para ter uma cota exclusiva de requisições por minuto.

Quando vale a pena? Se você sincroniza dezenas de milhares de arquivos ou usa várias contas ao mesmo tempo, ter seu próprio client_id e client_secret evita limites compartilhados e mantém a velocidade máxima.
1

Criar um projeto no Google Cloud Console

Acesse console.cloud.google.com com sua conta Google.

  • Clique no seletor de projetos no topo da página e depois em Novo projeto (New Project).
  • Dê um nome fácil de lembrar, como BrisaSync Pessoal, e clique em Criar.
  • Aguarde alguns segundos e selecione o projeto recém-criado no topo.
2

Ativar a Google Drive API

Com o projeto selecionado, habilite o acesso ao Google Drive:

  • No menu lateral, abra APIs e serviços → Biblioteca (APIs & Services → Library).
  • Busque por Google Drive API e clique no resultado oficial.
  • Clique no botão azul Ativar (Enable).
3

Configurar a tela de consentimento OAuth

Antes de gerar as chaves, o Google pede os dados básicos do aplicativo:

  • Vá em APIs e serviços → Tela de permissão OAuth (OAuth consent screen).
  • Escolha Externo (External) e clique em Criar.
  • Preencha o nome do app (ex.: BrisaSync) e seu e-mail nos campos obrigatórios.
  • Em Usuários de teste (Test users), adicione o seu próprio e-mail do Gmail.
Dica importante sobre os 7 dias: Projetos no modo Testing expiram a autorização a cada 7 dias. Para não precisar reconectar toda semana, clique em Publicar aplicativo (Publish App) na tela de consentimento — para uso pessoal, não é necessário passar pela verificação do Google (basta clicar em "Avançado → Ir para BrisaSync" na primeira vez).
4

Criar o ID do cliente OAuth (App para computador)

Agora gere o par de credenciais que o BrisaSync vai usar:

  • Abra APIs e serviços → Credenciais (Credentials).
  • Clique em + Criar credenciais → ID do cliente OAuth.
  • Em Tipo de aplicativo, selecione App para computador (Desktop app).
  • Clique em Criar e copie o Client ID e o Client Secret exibidos na janela.
5

Colar as credenciais no BrisaSync

Por fim, informe as chaves no aplicativo:

  • Abra o BrisaSync e vá em Ajustes → Avançado · Google Drive.
  • Cole o client_id e o client_secret nos campos correspondentes.
  • Clique em Salvar credenciais. O selo no topo mudará para seu projeto.
  • Se já tinha uma conta Google Drive conectada antes, desconecte e conecte novamente para passar a usar a nova cota.
